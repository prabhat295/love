# The photo for the welcome popup

Drop the photo of Shivani with the roses into **this folder**. Any filename,
any of `.jpg` `.jpeg` `.png` `.webp`.

That's it — no code to change. A photo in this folder automatically wins over
the Drive photo the popup is using right now.

If you put more than one here, the **first one alphabetically** is used. To pick
a specific one, name it `1.jpg` and the rest `2.jpg`, `3.jpg`…

Portrait photos are handled — the popup caps the height at 58% of the screen and
shows the whole photo rather than cropping it.

You can delete this file once your photo is in.
